# netwatch
NetWatch مشروع توعوي يهدف إلى رفع الوعي بمخاطر استخدام شبكات WiFi العامة غير الآمنة، والتي قد تؤدي إلى تسريب البيانات الشخصية دون علم المستخدم. يقدم تجربة تفاعلية تشمل ألعابًا وأسئلة ونصائح تساعد الأفراد على فهم المخاطر واتخاذ قرارات أكثر أمانًا أثناء الاتصال بالإنترنت في الأماكن العامة.
